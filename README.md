## ✨ What is CodeXa?

**CodeXa** is a modern web-based digital store built to provide a clean purchasing experience for customers while giving administrators a centralized dashboard to manage the entire store.

The project is designed around three principles:

> **⚡ Fast interactions · 🎨 Clean UI · 📱 Excellent mobile experience**

Whether a customer is browsing products or an administrator is processing orders and top-up requests, CodeXa aims to keep every workflow simple, clear, and responsive.

---

## 🚀 Features

### 🛍️ Storefront

- Modern landing page and storefront
- Product browsing and product information
- Responsive product cards
- Clean purchase/request flow
- Custom account/email request support
- Mobile-friendly navigation
- Smooth UI interactions

### 📦 Order Management

- Order tracking and management
- Customer/order information
- Product and account details
- Order status management
- Confirmation dialogs for destructive actions
- Loading and action feedback

### 💳 Top Up System

- Top-up request management
- Admin approval workflow
- Top-up history
- Request status handling
- Clear success/error feedback

### 👤 User Management

- User list and account information
- User activity management
- User-related order information
- Consistent data rendering

### 🔔 Notifications

- Admin/user notification support
- Notification status handling
- Notification deletion workflow
- Clear feedback after notification actions

### 🧑‍💻 Admin Panel

Centralized administration for:

- 📊 Store data
- 📦 Orders
- 🛍️ Products
- 👥 Users
- 💳 Top-ups
- 🔔 Notifications
- 📨 Custom requests

### 📨 Custom Email / Username Requests

Users can request a custom username/email according to the available rules.

The system is designed to validate:

- Format
- Availability
- Existing records
- Duplicate requests
- Backend uniqueness

This helps administrators create requested accounts without accidentally conflicting with an existing public username/email.

### 📱 Responsive UI

CodeXa is built to work across:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop screens

Layouts, cards, navigation, dialogs, tables, and forms are designed to remain usable on smaller screens.

### ⚡ UX & Feedback

Important actions should never leave the interface looking frozen or inactive.

CodeXa uses UX patterns such as:

- Loading states
- Disabled buttons during requests
- Confirmation modals
- Success/error notifications
- Smooth transitions
- Expandable long text
- Automatic data refresh after successful actions
- Scroll-to-top navigation behavior

## 🛠️ Development

### Requirements

- Node.js
- npm
- A Neon-compatible database configuration

### Install

```bash
git clone https://github.com/Kztutorial99/CodeXa.git
cd CodeXa
npm install
```

### Start Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

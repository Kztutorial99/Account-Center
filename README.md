## ✨ About CodeXa

**CodeXa** is a modern web-based store platform designed to make digital product management and purchasing simple, fast, and organized.

The project focuses on a polished user experience for both **customers and administrators**, with responsive layouts that work across desktop and mobile devices.

## 🚀 Highlights

- 🛍️ **Modern Store** — Clean storefront experience for browsing products.
- 📦 **Order Management** — Organized order and purchase management.
- 💳 **Top Up System** — Manage balance/top-up requests from the admin panel.
- 👤 **User Management** — View and manage registered users.
- 🧑‍💻 **Admin Panel** — Centralized tools for managing CodeXa.
- 🔔 **Notifications** — Keep users and administrators informed about important activity.
- 📱 **Responsive UI** — Designed to work comfortably on mobile and desktop.
- ✨ **Smooth UX** — Loading states, confirmations, transitions, and clear action feedback.
- 📨 **Custom Requests** — Support for custom username/email requests with availability validation.

## 🖥️ Main Areas

### 👥 User Store

Customers can browse available products, create orders, manage requests, and interact with the store through a responsive interface.

### 🛠️ Admin Panel

Administrators can manage:

- Products
- Orders
- Users
- Top-up requests
- Notifications
- Store data
- Custom account/email requests

## 📱 Responsive Design

CodeXa is designed with a **mobile-first mindset**, ensuring important pages and actions remain accessible and usable on smaller screens.

## 🔄 User Experience

Important actions should provide clear feedback instead of leaving the interface looking inactive. CodeXa uses patterns such as:

- Confirmation dialogs for destructive actions
- Button loading states
- Success and error feedback
- Expandable long text
- Automatic data refresh after successful actions
- Smooth page and component transitions

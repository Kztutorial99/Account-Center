# Project Overview

This workspace is used for lightweight GitHub API and repository tasks.

## User preferences

- Gunakan pendekatan hemat kuota: jalankan hanya perintah yang diperlukan, prioritaskan `curl`/`jq` untuk tugas GitHub, dan hindari pengulangan pemeriksaan tanpa alasan.

- Data aplikasi CodeXa harus berasal dari database Neon/Vercel; jangan menambahkan akun, produk, pesanan, kredensial, atau statistik dummy.

- Jangan gunakan database atau layanan managed Replit untuk aplikasi CodeXa. Gunakan Neon/Vercel yang sudah dikonfigurasi project, dan akses GitHub langsung melalui API `curl`/`jq` tanpa integrasi.
